## 3. Chat Request Sequence

The chat sequence outlines the synchronization loop between FastAPI, PostgreSQL key verification, and Ollama completion engines. This sequence is processed via standard Mermaid:

```mermaid
sequenceDiagram
    autonumber
    participant App as Client App
    participant CF as Cloudflare Tunnel
    participant API as FastAPI Gateway
    participant Limit as Chat Limiter
    participant DB as PostgreSQL
    participant O as Ollama

    App->>CF: POST /v1/chat/completions
    CF->>API: Forward to localhost gateway
    API->>DB: Validate API key
    API->>Limit: Acquire slot
    alt Slot acquired
        API->>O: Forward payload with keep_alive
        O-->>API: Completion or stream chunks
        API-->>App: OpenAI-compatible response
        API->>DB: Record usage metadata
        API->>Limit: Release slot
    else Slots busy
        API-->>App: 429 chat_concurrency_limit
    end
```
