# DESIGN SYSTEM

> Canonical visual and interaction system.

---

# DESIGN PHILOSOPHY

The interface should feel:

* architectural
* premium
* technical
* intelligent
* editorial
* systems-oriented

The experience should communicate:

* engineering maturity
* platform thinking
* production readiness
* enterprise AI credibility

---

# DESIGN INSPIRATION

Primary inspiration:

* Vercel
* Stripe
* OpenAI
* Anthropic
* Linear
* Railway
* Retool

---

# VISUAL STYLE

Preferred:

* clean layouts
* whitespace
* typography hierarchy
* subtle motion
* dark/light sophistication
* terminal-inspired sections
* architecture visuals

Avoid:

* excessive gradients
* AI neon aesthetics
* overly animated sections
* clutter
* startup template feel

---

# TYPOGRAPHY

Typography should feel:

* editorial
* technical
* premium
* readable
* calm

Prefer:

* strong hierarchy
* large headlines
* minimal text clutter
* consistent spacing

---

# COLOR SYSTEM

Colors should communicate:

* trust
* precision
* intelligence
* technical focus

Avoid:

* overly saturated palettes
* random accent colors
* visual noise

---

# MOTION PRINCIPLES

Animations should:

* guide attention
* feel subtle
* improve flow
* reinforce hierarchy

Use:

* Framer Motion
* smooth transitions
* minimal parallax
* staggered reveals

Avoid:

* excessive motion
* distracting animations
* gimmicks

---

# COMPONENT STYLE

Components should:

* feel modular
* feel reusable
* feel infrastructure-inspired

Preferred components:

* architecture cards
* terminal panels
* metrics blocks
* timeline systems
* engineering badges
* diagram containers

---

# LAYOUT PRINCIPLES

Layouts should:

* feel spacious
* feel intentional
* emphasize readability
* prioritize scanning

Avoid:

* cramped sections
* excessive columns
* visual overload

---

# ENGINEERING VISUALS

Use:

* Mermaid.js
* infra diagrams
* architecture flows
* topology maps
* orchestration visuals

The website should visually reinforce:

* systems engineering
* AI orchestration
* platform architecture
* scalability
