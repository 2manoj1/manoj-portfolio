# ARCHITECTURE PRINCIPLES

> Canonical engineering and system-design principles for the Manoj Portfolio platform.

---

# CORE PHILOSOPHY

This platform should feel engineered, not decorated.

The experience should communicate:

* systems thinking
* architecture depth
* production readiness
* technical precision
* engineering maturity

The UI should resemble:

* engineering infrastructure
* AI platform systems
* architecture dashboards
* developer tooling ecosystems

NOT:

* marketing-heavy SaaS clones
* generic startup templates
* flashy AI landing pages

---

# FRONTEND PRINCIPLES

## Use Modern Next.js Correctly

Always:

* prefer React Server Components
* minimize client components
* leverage streaming where appropriate
* preserve App Router conventions
* use metadata APIs correctly
* use server actions where useful

Avoid:

* unnecessary hydration
* large client bundles
* excessive useEffect usage
* prop-drilling complexity
* monolithic components

---

# COMPONENT DESIGN PRINCIPLES

Components should be:

* composable
* reusable
* isolated
* semantic
* scalable

Preferred characteristics:

* low coupling
* clear props
* predictable behavior
* accessibility-first
* responsive by default

Avoid:

* giant JSX files
* duplicated patterns
* inline complexity
* fragile abstractions

# UI PRINCIPLES

The interface should communicate:

* calm intelligence
* engineering focus
* technical trust
* architectural precision

Use:

* whitespace
* typography hierarchy
* subtle animation
* grid layouts
* terminal aesthetics
* system-inspired visuals

Avoid:

* excessive gradients
* random colors
* noisy shadows
* over-animation
* “AI neon” aesthetics

# PERFORMANCE PRINCIPLES

Optimize for:

* Core Web Vitals
* low hydration cost
* fast navigation
* SEO
* accessibility
* static optimization where possible

Always:

* lazy-load heavy components
* optimize images
* minimize JavaScript
* preserve semantic HTML
